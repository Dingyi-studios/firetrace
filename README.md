# 火迹（FireTrace）· 野火取证分析

火迹是一个可交互的野火复盘工作台，支持沿时间轴查看火势蔓延、无人机侦察、消防增援和灭火作业。

## 本地启动

使用 Node.js 22 和支持 WebGL 2 的浏览器。进入本项目目录执行：

```bash
npm ci
npm run dev -- --port 4173
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。第一次安装需要 npm 依赖，运行时所需的地图、模型和业务数据均在项目内生成。

构建静态产物：

```bash
npm run build
npm run preview -- --port 4173
```

## 在线访问与部署

在线地址为 [realkk.icu/firetrace/](https://realkk.icu/firetrace/)，个人主页的「探索项目」也提供入口。

```bash
npm ci
npm run build:vps
```

将生成的 `dist/` 内容部署到网站的 `/firetrace/` 路径。该构建会为脚本、样式和图片加上正确的路径前缀。生产环境直接使用已有 HTTPS 静态服务器，无需运行 Vite、Node.js 或数据库。更新时使用独立发布目录，校验文件后切换入口链接，保留旧目录用于回退。

运行时仍需要访问设备支持 WebGL 2，三维场景由访问设备的浏览器渲染。

## 操作演示

1. **事件**。拖动时间轴或点击「关键事件」，观察烧毁区、立体火舌和活动火线。二维地图用深橙色标记活动火线。
2. **无人机**。选择 FT-01 至 FT-09 任一对象，地图和相机将跟随它。播放和暂停时间轴可控制无人机、救援车辆、火焰及投放动画。切换至「全局视角」可继续自由查看地图。
3. **消防资源**。拖动时间轴到 H-743 或 H-531 出动后，选择该单位并点击「回放洒水」，可查看水流、落地飞溅和逐渐消退的水迹。T-131 可回放阻燃剂投放。将时间轴拖到 8 月 14 日 18:00 前后开始播放，可跟随 E-31、E-32 和 E-45 分批进场。增援队下车后前往作业点，随着施工进度延长防火线。三批车辆沿穿村公路行驶，在火场附近靠边停车。拖动进度条可同步查看车辆、队员和防火线。消防资源时间轴的绿色菱形可直接跳到各批队员下车。
4. 回到 **事件**，开启 **风向与风速**图层查看风流线。顶部 **设置 → 重置演示** 可重置投放、检测和视角。

## 模拟场景

- 过火面积和火线由同一套模拟火势推进数据生成。中段随条件变化出现新的扩张，接近受控时逐渐放缓。
- 四架火情无人机追踪活动火线，两架村落无人机交错巡查南溪村、峡谷溪村、北岭村和橡树坪村；另有两架持续监视密林大火，一架高空观察完整火场。
- 村落无人机沿连续航线匀速转场；火情目标经过平滑，机体保持稳定盘旋。飞机机头始终对准航线，投放与补给航段的速度保持均衡。
- 二维地图的单位标签提供无人机、固定翼、直升机、消防车、人员与推土机图标。
- 地形、道路、建筑、气象、遥测和作业数据均用于本地模拟回放。

## 验证

执行 `npm test` 检查航线速度、转向、机头朝向、投放同步及暂停和倒拖的一致性。

## 当前线上迭代

- 点击关键事件会平滑快进或倒放到目标时间，起点和终点减速，过程可被拖动、播放或暂停打断。
- 普通回放速度为原版的四分之一，消防航空器保持原飞行速度；全部位置和作业状态仍由同一事件时间确定。
- 五架灭火航空器循环执行投放、返航、取水或机场补给、返回火场。载荷、作业日志、累计用量与粒子动画按循环同步。
- 风流线采用加粗条带，过火区保留少量余火；两片高可燃物密林持续燃烧，红外读数区分火线扩张速度与燃料密度。
- 红外热点框投影在地面火点上。高空全景默认展开相机，最多显示四处主要热点。跟随镜头支持上下左右拖动。

当前线上版本为 v1.0.3，本仓库包含对应的应用源码与验证用例。

## 热像锁定与风场更新

热像热点先经过山体视线检查，遮挡后立即取消方框。检测与锁定有短暂延迟，小幅温差不会触发频繁切换，跟踪位置和温度逐渐变化。高空镜头最多显示四个主要热点，普通镜头最多两个。

风线数量从 160 增至 240，按独立的实际时间以当前回放 16× 时的流速持续移动。暂停事件、拖动时间条或调整播放倍速不会改变风线流速。风图层开启时以约 30 帧持续绘制；隐藏风图层且热像锁定稳定后恢复空闲渲染。后台页面仍停止绘制。

源码及发布包另有本地备份，线上更新采用独立发布目录和入口链接切换。
