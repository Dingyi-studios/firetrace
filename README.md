# 火迹（FireTrace）· 野火取证分析

FireTrace 是一个可交互的本地野火复盘工作台。项目以 Dilum Sanjaya 的 FireTrace 演示为参考，以简体中文呈现岭景山火的事故时间轴、无人机侦察和消防资源跟随。

[演示原帖](https://x.com/DilumSanjaya/status/2108241054298415258)

## 本地启动

使用 Node.js 22 和支持 WebGL 2 的浏览器。进入本项目目录执行：

```bash
npm ci
npm run dev -- --port 4173
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。第一次安装需要 npm 依赖，运行时所需的地图、模型和业务数据均在项目内生成。

构建静态产物：

```bash
npm run build
npm run preview -- --port 4173
```

## 操作演示

1. **事件**。拖动时间轴或点击「关键事件」，观察烧毁区、立体火舌和活动火线。二维地图用深橙色标记活动火线。
2. **无人机**。选择 FT-01 至 FT-06 任一对象，地图和相机将跟随它。播放和暂停时间轴可控制无人机、救援车辆、火焰及投放动画。切换至「全局视角」可继续自由查看地图。
3. **消防资源**。选择 H-743 或 H-531 后点击「回放洒水」，可查看水流、落地飞溅和逐渐消退的水迹。T-131 可回放阻燃剂投放。将时间轴拖到 8 月 14 日 18:00 前后开始播放，可跟随 E-31、E-32 和 E-45 分批进场。增援队下车后前往作业点，随着施工进度延长防火线。三批车辆沿穿村公路行驶，在火场附近靠边停车。拖动进度条可同步查看车辆、队员和防火线。消防资源时间轴的绿色菱形可直接跳到各批队员下车。
4. 回到 **事件**，开启 **风向与风速**图层查看风流线。顶部 **设置 → 重置演示** 可重置投放、检测和视角。

## 视频已展示事实

- 视频实际演示了 二维 / 三维 切换、火场时间回放、六架无人机的选中与相机、两种热成像色板、消防飞机和消防车跟随、阻燃剂投放联动以及风场开关。
- 事件列表、字段、标签和资源名依据拆解材料。编辑、添加、证据、备注、分享 等入口在视频中可见，原演示没有给出可据以复现的完整业务流程。本版保留入口并标注或显示演示状态。
- 原项目的确切框架、后端、数据源和设备接入尚未确认。遥测表中的读数是视频取样时的瞬时值。

## 本项目复现方案

- 用 **Vite、原生 JavaScript 和 Three.js** 实现。山地、河谷、公路、水库、植被和载具均为程序化资产。二维地图与三维场景共享地形和空间坐标。
- 预设火势到达时间驱动火缘和烧毁材质。事故时间同时驱动无人机、消防资源、空投与地面作业。三批增援及防火线的位置和时间采用预设模拟调度。热成像使用同一场景的第二相机及模拟热度色板。
- 业务时钟、地理读数、遥测、火灾图层和投放为演示数据。烧毁迹地、起火概率等图层沿用原界面的含义，对应的是本地模拟叠加。地图按关键空间关系复现，地形轮廓和动态读数与视频存在差异。
