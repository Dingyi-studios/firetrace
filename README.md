# 火迹（FireTrace）· 野火取证分析

火迹是一个可交互的野火复盘工作台，支持沿时间轴查看火势蔓延、无人机侦察、消防增援和灭火作业。

## 本地启动

使用 Node.js 22 和支持 WebGL 2 的浏览器。进入本项目目录执行：

```bash
npm ci
npm run dev -- --port 4173
```

浏览器打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。第一次安装需要 npm 依赖，运行时所需的地图、模型和业务数据均在项目内生成。

构建静态产物：

```bash
npm run build
npm run preview -- --port 4173
```

## 操作演示

1. **事件**。拖动时间轴或点击「关键事件」，观察烧毁区、立体火舌和活动火线。二维地图用深橙色标记活动火线。
2. **无人机**。选择 FT-01 至 FT-06 任一对象，地图和相机将跟随它。播放和暂停时间轴可控制无人机、救援车辆、火焰及投放动画。切换至「全局视角」可继续自由查看地图。
3. **消防资源**。拖动时间轴到 H-743 或 H-531 出动后，选择该单位并点击「回放洒水」，可查看水流、落地飞溅和逐渐消退的水迹。T-131 可回放阻燃剂投放。将时间轴拖到 8 月 14 日 18:00 前后开始播放，可跟随 E-31、E-32 和 E-45 分批进场。增援队下车后前往作业点，随着施工进度延长防火线。三批车辆沿穿村公路行驶，在火场附近靠边停车。拖动进度条可同步查看车辆、队员和防火线。消防资源时间轴的绿色菱形可直接跳到各批队员下车。
4. 回到 **事件**，开启 **风向与风速**图层查看风流线。顶部 **设置 → 重置演示** 可重置投放、检测和视角。

## 模拟场景

- 过火面积和火线由同一套模拟火势推进数据生成。中段随条件变化出现新的扩张，接近受控时逐渐放缓。
- 四架火情无人机追踪活动火线，两架村落无人机交错巡查南溪村、峡谷溪村、北岭村和橡树坪村。
- 地形、道路、建筑、气象、遥测和作业数据均用于本地模拟回放。
